DDPPlugin Network

The plugin sets up a server supporting the Distributed Display Protocol (DDP), which is used e.g. by xlights or LedFx.

Supported formats: RGB with 24-bit per pixel.

Configuration

No configuration available for this plugin.

xlights Configuration

Add Ethernet controller:

  • Name: Pixelix
  • IP Address: <IP-ADDRESS>
  • Protocol: DDP

Add Layout - Create new matrix:

  • Name: Matrix8x32

Matrix:

  • Direction: Horizontal
  • Strings: 8
  • Nodes/String: 32
  • Strands/String: 1
  • Starting Location: Top Left
  • Controller: Pixelix

Controller Connection:

  • Port: 1
  • Protocol: LED Panel Matrix

String Properties:

  • String Type: RGB Nodes

Appearance:

  • Pixel Size: 10
  • Pixel Style: Square
