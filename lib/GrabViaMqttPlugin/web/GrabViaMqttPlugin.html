GrabViaMqttPlugin Data

Connects to an MQTT server to receive JSON data and display it.

The filter identifies the value in the JSON payload to display. Config examples

Filter Example

JSON payload:

{"temperature": 22.5, "humidity": 60}

Filter:

{"temperature": true}
Format Text Tags
  • {#RRGGBB} - Solid text color
  • {lgv ...} - Linear vertical gradient
  • {lgh ...} - Linear horizontal gradient
  • {stc} - Activate solid text color
  • {lgtc} - Activate gradient text color
  • {hl}/{hc}/{hr} - Horizontal align L/C/R
  • {vt}/{vc}/{vb} - Vertical align T/C/B
  • {0xCC} - Special character code

Use "%f" for numbers, "%s" for strings.

Configuration
Filter to identify the value in the JSON response. See ArduinoJson filtering.
