GrabViaRestPlugin Data

Connects to a REST API to fetch JSON data and display results.

Configuration examples

Format tags:

  • {#RRGGBB} - Set solid text color
  • {lgv #RRGGBB,#RRGGBB,OFFSET,LENGTH} - Linear vertical gradient
  • {lgh #RRGGBB,#RRGGBB,OFFSET,LENGTH} - Linear horizontal gradient
  • {stc} - Activate solid text color
  • {lgtc} - Activate linear gradient text color
  • {hl}/{hc}/{hr} - Horizontal align left/center/right
  • {vt}/{vc}/{vb} - Vertical align top/center/bottom
  • {0xCC} - Special character code

Use "%f" for numbers, "%s" for strings.
