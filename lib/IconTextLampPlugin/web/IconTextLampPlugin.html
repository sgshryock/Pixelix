IconTextLampPlugin Display

Shows icon on left, text on right, and lamps at bottom.

Supports GIF and BMP files (24/32 bpp, no compression).

Supports Home Assistant MQTT discovery if enabled.

Text tags:

  • {#RRGGBB} - Solid text color
  • {lgv}/{lgh} - Gradient colors
  • {hl}/{hc}/{hr} - Horizontal alignment
  • {vt}/{vc}/{vb} - Vertical alignment
  • {0xCC} - Special character code
