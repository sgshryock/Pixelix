MqttService Service

Configure and manage MQTT broker connections.

Important: Primary broker publishes plugin, sensor, and service config data.

Notes:

  • First broker is primary connection
  • Plugin/sensor/service topics use primary
  • Additional brokers for dedicated plugins
  • TLS applies root CA, client cert and key
  • TLS without root CA is insecure
