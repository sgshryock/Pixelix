SignalDetectorPlugin Audio

Detects a signal combined with up to 2 frequencies.

Each frequency must be detected for a specific configurable time.

Plugin disables itself when nothing is detected.

Additional push notification can be configured (GET or POST).

Configuration
URL triggered if signal is detected. Use "POST http://..." for POST requests.
Tone 1
Values above 2000 recommended.
Tone 2
Values above 2000 recommended.
